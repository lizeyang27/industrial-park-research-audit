# 产业园区决策研究框架

本文件是产业园区稿件的读稿前问题框架，不是事实知识库。它不包含现实企业、园区或政策结论；其中任何问题、机制或指标都必须由当前任务的适用来源核验，不能仅凭本文件关闭审阅发现。

## 1. 先识别决策者

同一句“园区价值提升”，对不同参与方可能代表完全不同的结果。读稿前至少区分：

- 地方政府与职能部门：产业结构、税收、就业、土地集约、能耗环保、债务与区域竞争。
- 园区平台、业主或开发主体：拿地与建设成本、融资约束、租售回款、出租率、资产价值和退出路径。
- 运营与专业服务方：获客、服务成本、交付能力、收费方式、企业留存及服务是否能够形成收入或资产价值。
- 入园与潜在入园企业：生产适配、搬迁和停产成本、供应链、人才、能源、合规、融资与市场机会。
- 金融与资本提供方：现金流质量、偿债来源、估值假设、风险分担和退出条件。

不要把某一参与方的目标自动写成全体参与方的共同收益。对“政府意愿”“企业需求”或“市场选择”的概括，要求说明主体、辖区、时点和可观察依据。

## 2. 沿价值链追问机制

把文章主旨放入一条可被反驳的传导链，而不是停在口号：

```text
政策与要素条件
  -> 土地、融资与建设
  -> 空间产品及成本
  -> 招商、筛选与产业集聚
  -> 运营和企业服务
  -> 企业经营结果与留存
  -> 园区现金流、资产价值和区域产业结果
```

每个箭头分别检查：执行主体、投入、时间滞后、中间变量、替代解释、失败条件和可观察证据。相邻节点同时改善不自动证明前一节点造成后一节点。

## 3. 五组读稿前问题

### 空间经济

- 租金、售价、去化率、出租率、空置率和净吸纳量的定义、期间与分母是否一致？
- 增长来自价格、数量、产品结构、统计范围还是一次性项目？
- “轻资产”“重资产”“服务增值”对应谁的资本投入、风险和现金流？

### 产业机制

- 被描述的产业集聚是企业数量集中、上下游交易、人才共享、技术协作，还是仅有相似标签？
- 招商项目的投资额、用地、能耗、建设周期和供应链条件是否与园区承载能力相符？
- 个别企业或单个园区案例能否外推，适用条件和反例是什么？

### 政策落地

- 引用的是正式文件、政策解读、会议表述、执行案例还是作者推断？
- 发布机关、适用辖区、对象、有效期、例外和配套细则是否匹配当前主张？
- “政策支持”是否被越写成必然审批、必然补贴或政府动机？

### 参与方激励

- 国企、民企、政府和企业各自承担什么成本，获得什么收益，考核周期是否一致？
- 服务投入是否有预算、团队、专业资源、交付频率和反馈闭环，而非只有服务清单？
- 企业入驻、留存或搬迁还可能由租金、补贴、区位、供应链、客户和融资等哪些因素解释？

### 证据与决策

- 关键结论改变谁的什么决策？最低需要何种证据才足以行动？
- 数字是否能回到原表、单位、时间和计算式；引语是否能回到原发言人与语境？
- 哪些问题可在正文与附件中完成 `V1`，哪些需要政策与利益相关方语境 `V2`，哪些必须由行业案例或专家判断 `V3`？

## 4. 高频命题的反证方向

以下内容只用于生成问题，不预设文章错误：

- “空间价值下降、服务价值上升”：分别用什么可观察指标衡量，是否存在区域、周期或园区类型差异？
- “服务提升带来去化或租金改善”：同期招商策略、价格、交付批次和市场景气能否解释变化？
- “产业链集聚形成护城河”：企业之间是否存在可验证联系，还是只有行业标签并置？
- “政策推动模式复制”：政策授权、财政承受力、载体供给和执行能力是否具备可迁移条件？
- “企业不会/一定会迁移”：设备、客户、供应链、土地、人才及沉没成本是否支持绝对判断？
- “某赛道是园区招商风口”：项目体量、供地方式、建设周期、能耗和地方承载条件是否被纳入？

## 5. 与通用审计内核的接口

产业园区任务可以在通用问题台账中追加以下字段：

- `park_actor`：主张涉及的参与方。
- `value_chain_node`：主张位于价值链的哪个节点或箭头。
- `decision_variable`：会改变目标读者决策的变量。
- `mechanism_gap`：传导链中缺失的主体、投入、中间变量或时间条件。
- `domain_evidence_needed`：关闭问题所需的政策、市场、项目或专家证据。

这些字段只提供领域组织方式。风险仍使用 `R1`–`R3`，验证难度仍使用 `V1`–`V3`，文本可发现性仍使用 `T1`–`T3`；领域标签不能自动提高风险，也不能把私有经验升级为事实证据。
