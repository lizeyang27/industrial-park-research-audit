# 产业研究质控合成案例集

这些案例完全虚构，只用于测试审阅规则。案例中的行业、主体、事实和措辞均不对应任何真实文章或项目。审阅目标是指出需要核验的具体问题，而不是替作者补造证据。

## 案例一 检测能力被扩大为制造能力

草稿：

> 当地新建的综合检测中心已经具备航空发动机整机批量制造能力，这意味着高端装备产业链已经完整形成。

已知材料只说明该中心提供材料测试、计量校准和失效分析服务，没有提及生产线、制造许可或配套企业。

应发现：

- `DOMAIN / R3 / V1`：把检测服务扩大成整机制造，且把一个服务节点扩大成完整产业链。
- `CAUSALITY / R3 / V3`：即使检测中心投入使用，也不能单独证明产业链已经形成。

所需处理：核对项目正式文件和许可范围；分别描述检测能力与制造能力；若无产业链证据，删除或缩窄结论。

不应过度标记：如果正式文件确实将设施命名为“综合检测中心”，不应为了追求更专业的语感而擅自改名。

## 案例二 单个季度被写成全行业趋势

草稿：

> 近几年所有城市的公共算力利用率都在持续上升，这证明算力中心已经全面供不应求。

作者手中只有某运营商一个季度的设备使用记录，且不同地区采用的利用率口径不一致。

应发现：

- `EVIDENCE / R3 / V1`：“近几年”“所有城市”“持续上升”和“全面”均超出样本与时间范围。
- `CAUSALITY / R3 / V3`：利用率变化不能单独证明供不应求，还可能受调度方式、统计口径或设备检修影响。

所需处理：补充可比的跨地区、跨期数据和指标定义；无法补证时，只陈述该运营商在已观察季度的情况，并把行业判断标为待验证假设。

## 案例三 备案被写成投产许可

草稿：

> 废旧化学品再生项目完成普通项目备案后即可开工并直接投产，园区可以按此路径快速复制。

草稿没有说明项目所在地，也没有核对环保、安全生产、建设和经营环节可能适用的要求。

应发现：

- `COMPLIANCE / R3 / V2`：把备案等同于完整许可，并给出了可执行建议。
- `DOMAIN / R2 / V3`：“废旧化学品再生项目”的具体工艺和处理对象不明，适用规则可能不同。

所需处理：确认辖区、工艺、主体和阶段，查阅现行主管部门文件；在权威依据确认前删除“即可”和“直接投产”。审阅工具只提出核验要求，不自行宣告该路径违法。

## 案例四 经营风险被改写成动机指控

草稿：

> 仍在布局传统冷链的地区已经选错方向，经营不达预期的企业大多只是来骗取地方资源。

现有材料只有若干项目延期信息，没有关于企业动机、资金使用或地区产业策略的调查证据。

应发现：

- `AUDIENCE / R3 / V2`：对一类地区和企业作出可能损害声誉的动机指控。
- `EVIDENCE / R3 / V1`：项目延期不能证明骗取资源，也不能支持对所有相关地区的判断。
- `CAUSALITY / R2 / V3`：经营不达预期可能有需求、成本、管理或审批等多种原因。

所需处理：改为描述已核实的延期、履约或运营结果；删除动机推断；如需讨论风险，明确样本范围并区分事实与分析。

## 案例五 无效比较与模板化表达叠加

草稿：

> 在产业浪潮奔涌的时代，创新、协同与蝶变正在重塑未来。某农业无人机测试场的参观人数高于一座冷链仓库的合同客户数，因此前者所在地区的产业服务能力更成熟。

两个数字来自不同时间，衡量对象也不同。草稿没有解释为何参观人数能与合同客户数比较。

应发现：

- `STRUCTURE / R3 / V1`：不可比指标直接支撑了核心结论。
- `EVIDENCE / R2 / V1`：缺少共同统计期和指标定义。
- `STYLE / R1 / V1`：开场修辞不提供事实或逻辑，并延迟文章重点。

所需处理：先定义“产业服务能力”及可比指标；若没有共同口径，删除比较。开头直接说明研究对象、数据范围和结论边界。

## 案例六 不应过度标记的通俗类比

草稿：

> 可以把公共试验台理解为按时段预约的共享设备。这个比喻只用于解释使用方式，并不表示实际收费、产权和风险分担完全相同。

正文随后引用正式运营规则，分别说明预约、收费和责任边界。

预期结果：

- 不应仅因使用通俗类比就标记 `STYLE`。
- 不应要求删除已经明确说明局限、且由后续正式材料支持的解释。
- 可以建议检查目标读者是否需要该类比，但最多属于 `R1/V2`，不能升级为事实性问题。

反例意义：质控不是清除所有口语、比喻或谨慎限定。表达只要准确、有限定并帮助读者理解，就应允许保留。

## 使用这些案例测试输出

合格的审阅结果应准确指出锚点、类别、风险级、验证级、理由和所需证据，并把事实核验与文字优化分开。它不应虚构来源、自动接受建议改写、把风险提示写成最终法律结论，也不应因单个常见词语就推断文本来自 AI。
